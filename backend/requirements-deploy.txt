# ML stack for a CPU server. Install AFTER requirements.txt:

#   ultralytics        -> scripts only
#   transformers, timm -> scripts only
#   scikit-image       -> scripts only
#
# Dropping them removes roughly 1.5 GB of build output for capability the
# deployed service does not use.
